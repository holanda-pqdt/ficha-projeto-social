

# 🌐 Projeto HTML5 - Plataforma Social

Este projeto é uma simulação de uma **plataforma social** desenvolvida com foco nos fundamentos do **HTML5**, com estrutura semântica, formulários completos e uso de elementos multimídia.

---

## 📁 Estrutura de Páginas

- `index.html` – Página inicial com informações da organização e contato  
- `projetos.html` – Página com projetos sociais e formas de voluntariado/doação  
- `cadastro.html` – Formulário completo com validações e máscaras de input  

---

## 🧱 Tecnologias Utilizadas

- HTML5 (semântica completa)
- CSS3 (estilização responsiva)
- Formulários com validação nativa
- Máscaras de input (CPF, telefone, CEP) com JavaScript

---

## 📸 Imagens e Recursos

As imagens estão organizadas na pasta `/assets/images/`, e os estilos em `/assets/css/style.css`.

---

## 📬 Funcionalidades do Formulário

- Nome completo
- E-mail
- CPF (com máscara)
- Telefone (com máscara)
- Data de nascimento
- Endereço completo (CEP, cidade, estado)
- Validação com atributos HTML5
